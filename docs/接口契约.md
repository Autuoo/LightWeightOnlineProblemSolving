# 接口契约（v0.1）

本文件是前后端并行开发的**唯一依据**。W3 冻结后，任何变更需走变更记录。

---

## 0 通用约定

### 0.1 基础信息

| 项 | 值 |
|---|---|
| Base URL | `http://{host}/api` |
| 数据格式 | JSON，UTF-8 |
| 时间格式 | ISO-8601，如 `2026-11-15T10:32:11.123+08:00` |
| 鉴权方式 | `Authorization: Bearer {jwt}` |

### 0.2 统一响应包装

```json
{
  "code": 0,
  "message": "ok",
  "data": {},
  "traceId": "5f3a1c9e8b7d4a2f"
}
```

- `code = 0` 成功；非 0 为业务错误码。
- HTTP 状态码同时反映错误语义（见错误码表）。
- `traceId` 用于日志检索，前端可在错误提示中展示。

### 0.3 分页约定

请求：`?page=1&size=20`（page 从 1 开始，size 上限 100）

响应 `data`：

```json
{
  "records": [],
  "page": 1,
  "size": 20,
  "total": 137
}
```

### 0.4 错误码

| 业务码 | HTTP | 含义 | 前端处理建议 |
|---|---|---|---|
| 40001 | 400 | 参数校验失败 | 展示 `message` |
| 40002 | 400 | 不支持的语言 | 提示可用语言 |
| 40003 | 400 | 测试点序号重复 | 管理端表单内提示 |
| 40101 | 401 | 用户名或密码错误 | 表单内提示 |
| 40102 | 401 | 登录已过期 | 跳转登录页 |
| 40103 | 401 | 无效凭证 | 清除 Token 并跳转 |
| 40301 | 403 | 无权限 | 提示并返回上一页 |
| 40401 | 404 | 资源不存在 | 展示空态页 |
| 42901 | 429 | 评测队列已满 | 提示稍后重试，禁用提交按钮 5s |
| 42902 | 429 | 操作频率超限（提交 / AI 助教） | 倒计时提示 |
| 42903 | 429 | AI 助教今日额度已用完 | 提示次日再试 |
| 50001 | 500 | 系统内部错误 | 通用错误提示 |
| 50002 | 500 | 沙箱不可用 | 提示暂停提交 |
| 50003 | 500 | 评测超时未收敛 | 提示联系管理员 |
| 50004 | 500 | AI 助教模型不可用 | 提示"助教暂不可用" |
| 50005 | 500 | AI 助教达到步数上限 | 提示稍后重试 |

**权限**：匿名

**请求**

```json
{ "username": "stu001", "password": "Passw0rd!" }
```

**响应 200**

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "token": "eyJhbGciOiJIUzI1NiJ9...",
    "expiresIn": 7200,
    "user": { "id": 3, "username": "stu001", "nickname": "张三", "role": "STUDENT" }
  },
  "traceId": "..."

```

**错误**：`40101`

**约束**：`username` 3–32 字符，`password` 6–64 字符。

### 1.2 GET /api/auth/me

**权限**：登录

**响应 200**：`data` 为 `user` 对象（同 1.1）。

**错误**：`40102`、`40103`

## 2 题目

### 2.1 GET /api/problems

**权限**：登录

**Query**

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| page | int | 否 | 默认 1 |
| size | int | 否 | 默认 20 |
| keyword | string | 否 | 标题模糊搜索 |
| difficulty | int | 否 | 1 简单 / 2 中等 / 3 困难 |

**响应 200** `data.records[]` 元素：

```json
{
  "id": 1,
  "title": "A+B Problem",
  "difficulty": 1,
  "timeLimitMs": 1000,
  "memoryLimitMb": 256,
  "passed": true
}
```

`passed` 表示当前用户是否已有 AC 记录。

### 2.2 GET /api/problems/{id}

**权限**：登录

**响应 200**

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "id": 1,
    "title": "A+B Problem",
    "description": "## 题目描述\n输入两个整数...",
    "difficulty": 1,
    "timeLimitMs": 1000,
    "memoryLimitMb": 256,
    "languages": ["PYTHON3", "CPP17", "JAVA17"],
    "timeMultiplier": { "PYTHON3": 3, "CPP17": 1, "JAVA17": 2 },
    "samples": [
      { "input": "1 2", "output": "3" }
    ]
  },
  "traceId": "..."
}
```

**强约束**：响应中**绝不包含** `test_case` 的 `input` / `expected_output`。`samples` 来自题目表单独字段，仅样例。

**错误**：`40401`（不存在或不可见）

### 2.3 POST /api/admin/problems

**权限**：ADMIN

**请求**

```json
{
  "title": "A+B Problem",
  "description": "## 题目描述\n...",
  "difficulty": 1,
  "timeLimitMs": 1000,
  "memoryLimitMb": 256,
  "visible": 1
}
```

**响应 200**

```json
{ "code": 0, "message": "ok", "data": { "id": 7 }, "traceId": "..." }
```

**错误**：`40001`、`40301`

### 2.4 PUT /api/admin/problems/{id}

**权限**：ADMIN，语义同 2.3，`data` 为空对象。

### 2.5 POST /api/admin/problems/{id}/test-cases

**权限**：ADMIN

**说明**：整批替换该题测试点（先删后插，事务内）。

**请求**

```json
{
  "testCases": [
    { "orderNo": 1, "input": "1 2\n", "expectedOutput": "3\n", "score": 50 },
    { "orderNo": 2, "input": "5 7\n", "expectedOutput": "12\n", "score": 50 }
  ]
}
```

**校验**：`orderNo` 在批内唯一；`score` 之和建议为 100；单条 input/output ≤ 1MB。

**错误**：`40003`、`40401`

## 3 提交

### 3.1 POST /api/submissions

**权限**：登录

**请求**

```json
{
  "problemId": 1,
  "language": "PYTHON3",
  "code": "a, b = map(int, input().split())\nprint(a + b)\n"
}
```

**校验**

| 项 | 规则 |
|---|---|
| problemId | 必须存在且 `visible=1` |
| language | 枚举 `PYTHON3` / `CPP17` / `JAVA17` |
| code | 1 ≤ 长度 ≤ 65536 字符 |

**响应 200**

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "submissionId": 1024,
    "status": "AC",
    "reused": true
  },
  "traceId": "..."
}
```

- 新提交：`status = "PENDING"`，`reused = false`。
- 幂等命中：直接返回既有终态与分数，`reused = true`（幂等窗口默认 10 分钟，仅命中终态记录）。

**错误**

| 码 | 场景 |
|---|---|
| 40001 | 参数非法 / 代码超长 |
| 40002 | 语言不支持 |
| 40401 | 题目不存在或不可见 |
| 42901 | 评测队列已满（此时不落库） |
| 42902 | 同一用户 60 秒内提交超过 10 次 |

**幂等说明**：`codeHash = SHA-256(language + "\n" + code)`，与 `(userId, problemId)` 组合判定。

### 3.2 GET /api/submissions/{id}

**权限**：本人或 ADMIN

**响应 200（终态示例）**

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "id": 1024,
    "problemId": 1,
    "problemTitle": "A+B Problem",
    "language": "PYTHON3",
    "status": "WA",
    "score": 50,
    "execTimeMs": 38,
    "memoryKb": 9216,
    "compileOutput": "",
    "errorMessage": null,
    "createdAt": "2026-11-15T10:32:11.123+08:00",
    "finishedAt": "2026-11-15T10:32:13.001+08:00",
    "cases": [
      { "caseId": 1, "orderNo": 1, "status": "AC", "execTimeMs": 18, "memoryKb": 9216 },
      { "caseId": 2, "orderNo": 2, "status": "WA", "execTimeMs": 20, "memoryKb": 9100 }
    ]
  },
  "traceId": "..."
}
```

**非终态**：`status` 为 `PENDING` / `COMPILING` / `RUNNING`，`cases` 可能为空数组，前端据此判断"仍在评测"。

**错误**：`40301`（非本人非管理员）、`40401`

### 3.3 GET /api/submissions

**权限**：登录，仅返回本人记录（ADMIN 可传 `userId` 查他人）

**Query**：`page`、`size`、`problemId`（可选）、`status`（可选）

**响应 200** `data.records[]` 元素为 3.2 的摘要（不含 `code` 与 `cases`）。

## 4 WebSocket

### 4.1 连接

| 项 | 值 |
|---|---|
| 端点 | `ws://{host}/ws`（或 SockJS `/ws`） |
| 协议 | STOMP |
| 握手鉴权 | 查询参数 `?token={jwt}` 或 STOMP CONNECT 头 `Authorization` |
| 应用前缀 | `/app` |
| 订阅前缀 | `/topic` |

### 4.2 订阅

```
SUBSCRIBE
destination:/topic/submissions/1024
```

**鉴权**：订阅拦截器校验该 `submissionId` 归属当前用户或当前用户为 ADMIN，否则发送 ERROR 帧并断开。

### 4.3 事件负载

```json
{
  "type": "SUBMISSION_STATUS_CHANGED",
  "submissionId": 1024,
  "status": "AC",
  "score": 100,
  "execTimeMs": 38,
  "memoryKb": 9216,
  "finishedAt": "2026-11-15T10:32:13.001+08:00"
}
```

**推送时机**：每次状态变更一次。终态后服务端不再推送，前端收到终态后主动 `UNSUBSCRIBE`。

### 4.4 可靠性约定

1. 前端订阅成功后**必须**先 `GET /api/submissions/{id}` 拉快照。
2. 收到事件按 `status` 合并；终态事件覆盖一切非终态。
3. 断线重连后重复步骤 1。
4. 连接失败或 5 秒内无消息，降级为 1.5s 轮询。

## 6 AI 助教（可选增量模块）

> 详细设计见《AI 助教增量设计》。总开关 `OJ_AI_ENABLED`，关闭时本组接口统一返回 `40401`。

### 6.1 POST /api/submissions/{id}/hint

**权限**：本人（管理员不可代问，避免越权读取他人代码）

**说明**：对一次已进入终态的提交提问，返回 SSE 流。

**请求**（`Content-Type: application/json`）

```json
{ "question": "为什么只过了一半？", "level": 2 }
```

| 字段 | 规则 |
|---|---|
| question | 可选，1–500 字符；为空时使用默认问题"请分析这次提交为什么没有通过" |
| level | 可选，1–3；1 思路 / 2 定位 / 3 检查点，默认 1；层级越高越具体 |
| 路径 id | 提交必须存在、属于当前用户、状态为终态；已 AC 的提交不提供助教（返回 40001） |

**响应**（`Content-Type: text/event-stream`）

```
event: token
data: {"text":"你的代码在"}

event: tool_call
data: {"tool":"get_failure_summary","ok":true,"elapsedMs":12}

event: token
data: {"text":"第 2 个测试点输出长度不符"}

event: done
data: {"hintId":88,"status":"OK","level":2,"reused":false,"tokens":452}
```

| 事件 | 含义 |
|---|---|
| `token` | 增量文本，前端追加渲染 |
| `tool_call` | 工具调用轨迹（只含工具名、成功与否、耗时，**不含数据内容**） |
| `done` | 正常结束，携带 `hintId` 与状态 |
| `error` | 流内错误，`data` 含 `code` 与 `message` |

**错误（流开始前，返回标准 JSON 包装）**

| 码 | 场景 |
|---|---|
| 40001 | question 超长 / 参数非法 / 提交已 AC |
| 40301 | 提交不属于当前用户 |
| 40401 | 模块未启用 / 提交不存在 / 提交尚未进入终态 |
| 42902 | 同一提交在最小间隔内重复请求（默认关闭，间隔可配置） |
| 42903 | 当日额度用尽（个人 100 次 / 全局 500 次） |
| 50004 | 模型端点不可达 |

**流内错误**：`50004` 模型中断、`50005` 达到步数上限、`TIMEOUT` 超时。已生成内容保留。

**约束**

- 总超时 30 秒，超时后发送 `done` 且 `status=TIMEOUT`。
- 最大 3 轮工具调用。
- 服务端对工具参数做类型与归属校验，不信任模型输出。
- 返回内容**不得包含**任何测试点输入或期望输出（阻断级约束）。

### 6.2 GET /api/ai/status

返回模块是否启用，前端据此决定是否渲染助教入口。

```json
{ "code": 0, "data": { "enabled": true, "model": "deepseek-chat", "dailyUserQuota": 100, "maxLevel": 3 } }
```

### 6.3 GET /api/submissions/{id}/hints

**权限**：本人。返回该提交最近 20 条问答，按时间正序。

```json
{
  "code": 0,
  "data": [
    {
      "id": 88,
      "question": "为什么只过了一半？",
      "answer": "先检查输出结尾是否多了空行……",
      "level": 2,
      "status": "OK",
      "stepCount": 2,
      "createdAt": "2026-11-15T10:40:00.000+08:00"
    }
  ]
}
```

**复用规则**：同一提交 + 同一问题 + 同一 `level` 且 `status=OK` 时，直接回放已存回答（`done.reused=true`），不消耗额度、不调用模型。

### 6.4 前端接入约定

1. 使用 `fetch` + `ReadableStream` 解析 SSE，**不能用 `EventSource`**（它不支持带 Header 的 POST）。
2. 收到 `tool_call` 时展示"正在查看失败摘要"之类的过程提示，而非静默等待。
3. 收到 `done` 或 `error` 后关闭 reader 并释放流。
4. 未收到 `done` 即断流，按异常处理并提示"回答中断，请重试"。
5. 入口按钮仅在提交状态为 WA/TLE/MLE/RE/CE 时显示。

## 7 用户管理（管理员）

所有接口均要求 `ADMIN` 角色。

### 7.1 GET /api/admin/users

**参数**：`page`（默认 1）、`size`（默认 20，上限 100）、`keyword`（可选，匹配用户名或昵称）。

```json
{
  "code": 0,
  "data": {
    "records": [
      { "id": 2, "username": "stu001", "nickname": "示例学生", "role": "STUDENT", "status": 1, "createdAt": "2026-11-15T19:26:53.226+08:00" }
    ],
    "page": 1,
    "size": 20,
    "total": 2
  }
}
```

### 7.2 PATCH /api/admin/users/{id}/status

```json
{ "status": 0 }
```

| 约束 | 说明 |
|---|---|
| 不能禁用自己 | 返回 `40001` |
| 不能禁用最后一个启用的管理员 | 返回 `40001` |
| `status` 取值 | 仅 0（禁用）或 1（启用） |

禁用后：该账号的旧 JWT 立即失效，请求返回 `40301 账号已被禁用`；重新登录同样被拒。

### 7.3 POST /api/admin/users/{id}/reset-password

无请求体，重置为配置的默认密码。

```json
{ "code": 0, "data": { "password": "12345678" } }
```

默认值由 `OJ_ADMIN_RESET_PASSWORD` 控制，默认 `12345678`。
