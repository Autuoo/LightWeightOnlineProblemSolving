# 接口契约（v1.0）

本文件是前后端并行开发的**唯一依据**。W3 冻结后，任何变更需走变更记录。

---

## 0 通用约定

### 0.1 基础信息

| 项 | 值 |
|---|---|
| Base URL | `http://{host}/api` |
| 数据格式 | JSON，UTF-8 |
| 时间格式 | ISO-8601，如 `2026-11-15T10:32:11.123+08:00` |
| 鉴权方式 | `Authorization: Bearer {jwt}` |

### 0.2 统一响应包装

```json
{
  "code": 0,
  "message": "ok",
  "data": {},
  "traceId": "5f3a1c9e8b7d4a2f"
}
```

- `code = 0` 成功；非 0 为业务错误码。
- HTTP 状态码同时反映错误语义（见错误码表）。
- `traceId` 用于日志检索，前端可在错误提示中展示。

### 0.3 分页约定

请求：`?page=1&size=20`（page 从 1 开始，size 上限 100）

响应 `data`：

```json
{
  "records": [],
  "page": 1,
  "size": 20,
  "total": 137
}
```

### 0.4 错误码

| 业务码 | HTTP | 含义 | 前端处理建议 |
|---|---|---|---|
| 40001 | 400 | 参数校验失败 | 展示 `message` |
| 40002 | 400 | 不支持的语言 | 提示可用语言 |
| 40003 | 400 | 测试点序号重复 | 管理端表单内提示 |
| 40101 | 401 | 用户名或密码错误 | 表单内提示 |
| 40102 | 401 | 登录已过期 | 跳转登录页 |
| 40103 | 401 | 无效凭证 | 清除 Token 并跳转 |
| 40301 | 403 | 无权限 | 提示并返回上一页 |
| 40401 | 404 | 资源不存在 | 展示空态页 |
| 42901 | 429 | 评测队列已满 | 提示稍后重试，禁用提交按钮 5s |
| 42902 | 429 | 操作频率超限（提交 / AI 助教） | 倒计时提示 |
| 42903 | 429 | AI 助教今日额度已用完 | 提示次日再试 |
| 50001 | 500 | 系统内部错误 | 通用错误提示 |
| 50002 | 500 | 沙箱不可用 | 提示暂停提交 |
| 50003 | 500 | 评测超时未收敛 | 提示联系管理员 |
| 50004 | 500 | AI 助教模型不可用 | 提示"助教暂不可用" |
| 50005 | 500 | AI 助教达到步数上限 | 提示稍后重试 |

## 1 认证

### 1.1 POST /api/auth/login

**权限**：匿名

**请求**

```json
{ "username": "stu001", "password": "Passw0rd!" }
```

**响应 200**

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "token": "eyJhbGciOiJIUzI1NiJ9...",
    "expiresIn": 7200,
    "user": { "id": 3, "username": "stu001", "nickname": "张三", "role": "STUDENT" }
  },
  "traceId": "..."
}
```

**错误**：`40101`

**约束**：`username` 3–32 字符，`password` 6–64 字符。

### 1.2 GET /api/auth/me

**权限**：登录

**响应 200**：`data` 为 `user` 对象（同 1.1）。

**错误**：`40102`、`40103`

### 1.3 POST /api/auth/register

**权限**：匿名

**说明**：学生自助注册，成功后直接签发登录态。

**请求**

```json
{ "username": "stu002", "nickname": "李四", "password": "Passw0rd!" }
```

**响应 200**：与 1.1 登录响应结构一致（`token`、`expiresIn`、`user`）。

**约束**

| 字段 | 规则 |
|---|---|
| username | 3–32 位字母、数字、下划线，全局唯一 |
| nickname | 可选，最长 32 字符，默认与用户名相同 |
| password | 6–64 字符，BCrypt 加密存储 |

**错误**：`40001`（格式不合法或用户名已存在）

## 2 题目

### 2.1 GET /api/problems

**权限**：登录

**Query**

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| page | int | 否 | 默认 1 |
| size | int | 否 | 默认 20 |
| keyword | string | 否 | 标题模糊搜索 |
| difficulty | int | 否 | 1 简单 / 2 中等 / 3 困难 |

**响应 200** `data.records[]` 元素：

```json
{
  "id": 1,
  "title": "A+B Problem",
  "difficulty": 1,
  "timeLimitMs": 1000,
  "memoryLimitMb": 256,
  "passed": true
}
```

`passed` 表示当前用户是否已有 AC 记录。

### 2.2 GET /api/problems/{id}

**权限**：登录

**响应 200**

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "id": 1,
    "title": "A+B Problem",
    "description": "## 题目描述\n输入两个整数...",
    "difficulty": 1,
    "timeLimitMs": 1000,
    "memoryLimitMb": 256,
    "languages": ["PYTHON3", "CPP17", "JAVA17"],
    "timeMultiplier": { "PYTHON3": 3, "CPP17": 1, "JAVA17": 2 },
    "samples": [
      { "input": "1 2", "output": "3" }
    ]
  },
  "traceId": "..."
}
```

**强约束**：响应中**绝不包含** `test_case` 的 `input` / `expected_output`。`samples` 来自题目表单独字段，仅样例。

**错误**：`40401`（不存在或不可见）

### 2.3 POST /api/admin/problems

**权限**：ADMIN

**请求**

```json
{
  "title": "A+B Problem",
  "description": "## 题目描述\n...",
  "difficulty": 1,
  "timeLimitMs": 1000,
  "memoryLimitMb": 256,
  "visible": 1
}
```

**响应 200**

```json
{ "code": 0, "message": "ok", "data": { "id": 7 }, "traceId": "..." }
```

**错误**：`40001`、`40301`

### 2.4 PUT /api/admin/problems/{id}

**权限**：ADMIN，语义同 2.3，`data` 为空对象。

### 2.5 POST /api/admin/problems/{id}/test-cases

**权限**：ADMIN

**说明**：整批替换该题测试点（先删后插，事务内）。

**请求**

```json
{
  "testCases": [
    { "orderNo": 1, "input": "1 2\n", "expectedOutput": "3\n", "score": 50 },
    { "orderNo": 2, "input": "5 7\n", "expectedOutput": "12\n", "score": 50 }
  ]
}
```

**校验**：`orderNo` 在批内唯一；`score` 之和建议为 100；单条 input/output ≤ 1MB。

**错误**：`40003`、`40401`

### 2.6 GET /api/admin/problems

**权限**：ADMIN。管理员视角的题目列表，包含不可见题目。

**参数**：`page`（默认 1）、`size`（默认 20，上限 100）、`keyword`（标题模糊搜索）、`difficulty`（1-3）。

```json
{
  "code": 0,
  "data": {
    "records": [
      { "id": 4, "title": "回文串判断", "difficulty": 2, "tags": "字符串,双指针", "visible": 1, "timeLimitMs": 1000, "memoryLimitMb": 256, "caseCount": 6, "createdAt": "2026-11-18T15:00:00.000+08:00" }
    ],
    "page": 1,
    "size": 20,
    "total": 6
  }
}
```

### 2.7 GET /api/admin/problems/{id}

**权限**：ADMIN。返回完整题面、样例与测试点，用于编辑已有题目。

```json
{
  "code": 0,
  "data": {
    "id": 4,
    "title": "回文串判断",
    "description": "## 题目描述…",
    "samples": [{ "input": "level\n", "output": "YES\n" }],
    "difficulty": 2,
    "tags": "字符串,双指针",
    "timeLimitMs": 1000,
    "memoryLimitMb": 256,
    "visible": 1,
    "testCases": [{ "orderNo": 1, "input": "level\n", "expectedOutput": "YES\n", "score": 17 }]
  }
}
```

### 2.8 DELETE /api/admin/problems/{id}

**权限**：ADMIN

**说明**：物理删除题目，并在事务内级联清理关联数据。

**删除顺序**

1. 该题所有提交对应的 `submission_case_result`
2. 该题所有提交对应的 `ai_hint`
3. 该题所有 `submission`
4. 该题所有 `test_case`
5. `problem`

**响应 200**

```json
{ "code": 0, "message": "ok", "data": null, "traceId": "..." }
```

**错误**：`40401`（题目不存在）、`40301`（非管理员）

**约束**

- 删除不可恢复；前端必须二次确认，并明确提示「测试点与提交记录会一并删除」。
- 删除完成后，学生端题库与提交记录中不再出现该题数据。

## 3 提交

### 3.1 POST /api/submissions

**权限**：登录

**请求**

```json
{
  "problemId": 1,
  "language": "PYTHON3",
  "code": "a, b = map(int, input().split())\nprint(a + b)\n"
}
```

**校验**

| 项 | 规则 |
|---|---|
| problemId | 必须存在且 `visible=1` |
| language | 枚举 `PYTHON3` / `CPP17` / `JAVA17` |
| code | 1 ≤ 长度 ≤ 65536 字符 |

**响应 200**

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "submissionId": 1024,
    "status": "AC",
    "reused": true
  },
  "traceId": "..."
}
```

- 新提交：`status = "PENDING"`，`reused = false`。
- 幂等命中：直接返回既有终态与分数，`reused = true`（幂等窗口默认 10 分钟，仅命中终态记录）。

**错误**

| 码 | 场景 |
|---|---|
| 40001 | 参数非法 / 代码超长 |
| 40002 | 语言不支持 |
| 40401 | 题目不存在或不可见 |
| 42901 | 评测队列已满（此时不落库） |


**幂等说明**：`codeHash = SHA-256(language + "\n" + code)`，与 `(userId, problemId)` 组合判定。

### 3.2 GET /api/submissions/{id}

**权限**：本人或 ADMIN

**响应 200（终态示例）**

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "id": 1024,
    "problemId": 1,
    "problemTitle": "A+B Problem",
    "language": "PYTHON3",
    "status": "WA",
    "score": 50,
    "execTimeMs": 38,
    "memoryKb": 9216,
    "compileOutput": "",
    "errorMessage": null,
    "createdAt": "2026-11-15T10:32:11.123+08:00",
    "finishedAt": "2026-11-15T10:32:13.001+08:00",
    "cases": [
      { "caseId": 1, "orderNo": 1, "status": "AC", "execTimeMs": 18, "memoryKb": 9216 },
      { "caseId": 2, "orderNo": 2, "status": "WA", "execTimeMs": 20, "memoryKb": 9100 }
    ]
  },
  "traceId": "..."
}
```

**非终态**：`status` 为 `PENDING` / `COMPILING` / `RUNNING`，`cases` 可能为空数组，前端据此判断"仍在评测"。

**错误**：`40301`（非本人非管理员）、`40401`

### 3.3 GET /api/submissions

**权限**：登录，仅返回本人记录（ADMIN 可传 `userId` 查他人）

**Query**：

| 参数 | 说明 |
|---|---|
| `page` / `size` | 分页，`size` 上限 100 |
| `problemId` | 可选，按题目筛选 |
| `contestId` | 可选，按比赛筛选（仅本人提交） |
| `status` | 可选，AC / WA / TLE / MLE / RE / CE 等 |
| `keyword` | 可选，按题目标题模糊搜索 |
| `from` / `to` | 可选，日期 `YYYY-MM-DD`，含当天；可单独使用 |
| `suspicious` | 可选，`true` / `false`，按打表特征标记过滤 |

**响应 200** `data.records[]` 元素为 3.2 的摘要（不含 `code` 与 `cases`），另含 `suspicious` 布尔标记。

### 3.4 GET /api/admin/submissions

**权限**：ADMIN。全部学生的提交记录，参数与 3.3 相同，额外支持 `userId`。

**响应** `data.records[]` 额外包含 `username`：

```json
{
  "id": 16,
  "userId": 2,
  "username": "stu001",
  "problemTitle": "A+B Problem",
  "language": "PYTHON3",
  "status": "WA",
  "score": 17,
  "createdAt": "2026-11-18T21:10:00.000",
  "suspicious": true
}
```

`suspicious=true` 表示启发式检测命中打表特征（按输入字符串分支并输出常量、多级 `elif`、未读输入直接输出等），**仅用于人工审查，不改变得分**。

### 3.5 POST /api/submissions/custom-run

**权限**：登录

**说明**：使用学生自定义的标准输入运行当前代码，用于调试；**不创建 submission、不写逐点结果、不影响统计与排行榜**，也不会读取任何隐藏测试点。

**请求**

```json
{
  "problemId": 5,
  "language": "PYTHON3",
  "code": "print(int(input()) * 2)",
  "input": "21\n"
}
```

**校验**

| 项 | 规则 |
|---|---|
| problemId | 必须存在且 `visible=1` |
| language | `PYTHON3` / `CPP17` / `JAVA17` |
| code | 1 ≤ 长度 ≤ 65536 字符 |
| input | 可为空，长度 ≤ 65536 字符 |

**响应 200**

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "status": "OK",
    "exitCode": 0,
    "timeMs": 51,
    "memoryKb": 0,
    "stdout": "42\r\n",
    "stderr": "",
    "compileOutput": ""
  },
  "traceId": "..."
}
```

**状态判定**

| status | 含义 |
|---|---|
| `OK` | 正常退出（exitCode=0） |
| `CE` | 编译失败，`compileOutput` 含编译器输出 |
| `TLE` | 超过题目时限，进程被终止 |
| `RE` | 非零退出或运行异常，`stderr`/`exitCode` 说明原因 |

**约束**

- 时间限制与题目 `timeLimitMs` 一致，不复用评测队列。
- `stdout` / `stderr` / `compileOutput` 超过 64 KB 会截断，并追加截断标记。
- 运行前后提交记录总数不变。

**错误**：`40001`（输入/代码超长）、`40002`（语言不支持）、`40401`（题目不存在或不可见）

## 4 WebSocket

### 4.1 连接

| 项 | 值 |
|---|---|
| 端点 | `ws://{host}/ws`（或 SockJS `/ws`） |
| 协议 | STOMP |
| 握手鉴权 | 查询参数 `?token={jwt}` 或 STOMP CONNECT 头 `Authorization` |
| 应用前缀 | `/app` |
| 订阅前缀 | `/topic` |

### 4.2 订阅

```
SUBSCRIBE
destination:/topic/submissions/1024
```

**鉴权**：订阅拦截器校验该 `submissionId` 归属当前用户或当前用户为 ADMIN，否则发送 ERROR 帧并断开。

### 4.3 事件负载

```json
{
  "type": "SUBMISSION_STATUS_CHANGED",
  "submissionId": 1024,
  "status": "AC",
  "score": 100,
  "execTimeMs": 38,
  "memoryKb": 9216,
  "finishedAt": "2026-11-15T10:32:13.001+08:00"
}
```

**推送时机**：每次状态变更一次。终态后服务端不再推送，前端收到终态后主动 `UNSUBSCRIBE`。

### 4.4 可靠性约定

1. 前端订阅成功后**必须**先 `GET /api/submissions/{id}` 拉快照。
2. 收到事件按 `status` 合并；终态事件覆盖一切非终态。
3. 断线重连后重复步骤 1。
4. 连接失败或 5 秒内无消息，降级为 1.5s 轮询。

## 6 AI 助教（可选增量模块）

> 详细设计见《AI 助教增量设计》。总开关 `OJ_AI_ENABLED`，关闭时本组接口统一返回 `40401`。

### 6.1 POST /api/submissions/{id}/hint

**权限**：本人（管理员不可代问，避免越权读取他人代码）

**说明**：对一次已进入终态的提交提问，返回 SSE 流。

**请求**（`Content-Type: application/json`）

```json
{ "question": "为什么只过了一半？", "level": 2 }
```

| 字段 | 规则 |
|---|---|
| question | 可选，1–500 字符；为空时使用默认问题"请分析这次提交为什么没有通过" |
| level | 可选，1–3；1 思路 / 2 定位 / 3 检查点，默认 1；层级越高越具体 |
| 路径 id | 提交必须存在、属于当前用户、状态为终态；已 AC 的提交不提供助教（返回 40001） |

**响应**（`Content-Type: text/event-stream`）

```
event: token
data: {"text":"你的代码在"}

event: tool_call
data: {"tool":"get_failure_summary","ok":true,"elapsedMs":12}

event: token
data: {"text":"第 2 个测试点输出长度不符"}

event: done
data: {"hintId":88,"status":"OK","level":2,"reused":false,"tokens":452}
```

| 事件 | 含义 |
|---|---|
| `token` | 增量文本，前端追加渲染 |
| `tool_call` | 工具调用轨迹（只含工具名、成功与否、耗时，**不含数据内容**） |
| `done` | 正常结束，携带 `hintId` 与状态 |
| `error` | 流内错误，`data` 含 `code` 与 `message` |

**错误（流开始前，返回标准 JSON 包装）**

| 码 | 场景 |
|---|---|
| 40001 | question 超长 / 参数非法 / 提交已 AC |
| 40301 | 提交不属于当前用户 |
| 40401 | 模块未启用 / 提交不存在 / 提交尚未进入终态 |
| 42902 | 同一提交在最小间隔内重复请求（默认关闭，间隔可配置） |
| 42903 | 当日额度用尽（个人 100 次 / 全局 500 次） |
| 50004 | 模型端点不可达 |

**流内错误**：`50004` 模型中断、`50005` 达到步数上限、`TIMEOUT` 超时。已生成内容保留。

**约束**

- 总超时 30 秒，超时后发送 `done` 且 `status=TIMEOUT`。
- 最大 3 轮工具调用。
- 服务端对工具参数做类型与归属校验，不信任模型输出。
- 返回内容**不得包含**任何测试点输入或期望输出（阻断级约束）。

### 6.2 GET /api/ai/status

返回模块是否启用，前端据此决定是否渲染助教入口。

```json
{ "code": 0, "data": { "enabled": true, "model": "deepseek-chat", "dailyUserQuota": 100, "maxLevel": 3 } }
```

### 6.3 GET /api/submissions/{id}/hints

**权限**：本人。返回该提交最近 20 条问答，按时间正序。

```json
{
  "code": 0,
  "data": [
    {
      "id": 88,
      "question": "为什么只过了一半？",
      "answer": "先检查输出结尾是否多了空行……",
      "level": 2,
      "status": "OK",
      "stepCount": 2,
      "createdAt": "2026-11-15T10:40:00.000+08:00"
    }
  ]
}
```

**复用规则**：同一提交 + 同一问题 + 同一 `level` 且 `status=OK` 时，直接回放已存回答（`done.reused=true`），不消耗额度、不调用模型。

### 6.4 前端接入约定

1. 使用 `fetch` + `ReadableStream` 解析 SSE，**不能用 `EventSource`**（它不支持带 Header 的 POST）。
2. 收到 `tool_call` 时展示"正在查看失败摘要"之类的过程提示，而非静默等待。
3. 收到 `done` 或 `error` 后关闭 reader 并释放流。
4. 未收到 `done` 即断流，按异常处理并提示"回答中断，请重试"。
5. 入口按钮仅在提交状态为 WA/TLE/MLE/RE/CE 时显示。

## 7 用户管理（管理员）

所有接口均要求 `ADMIN` 角色。

### 7.1 GET /api/admin/users

**参数**：`page`（默认 1）、`size`（默认 20，上限 100）、`keyword`（可选，匹配用户名或昵称）。

```json
{
  "code": 0,
  "data": {
    "records": [
      { "id": 2, "username": "stu001", "nickname": "示例学生", "role": "STUDENT", "status": 1, "avatarUrl": null, "createdAt": "2026-11-15T19:26:53.226+08:00" }
    ],
    "page": 1,
    "size": 20,
    "total": 2
  }
}
```

### 7.2 PATCH /api/admin/users/{id}/status

```json
{ "status": 0 }
```

| 约束 | 说明 |
|---|---|
| 不能禁用自己 | 返回 `40001` |
| 不能禁用最后一个启用的管理员 | 返回 `40001` |
| `status` 取值 | 仅 0（禁用）或 1（启用） |

禁用后：该账号的旧 JWT 立即失效，请求返回 `40301 账号已被禁用`；重新登录同样被拒。

### 7.3 POST /api/admin/users/{id}/reset-password

无请求体，重置为配置的默认密码。

```json
{ "code": 0, "data": { "password": "12345678" } }
```

默认值由 `OJ_ADMIN_RESET_PASSWORD` 控制，默认 `12345678`。

### 7.4 POST /api/admin/users

创建学生账号（角色固定 `STUDENT`，状态默认启用）。

```json
{ "username": "stu002", "nickname": "演示学生", "password": null }
```

| 字段 | 规则 |
|---|---|
| username | 必填，3–32 位字母/数字/下划线，全局唯一 |
| nickname | 可选，≤32 字符；为空时取用户名 |
| password | 可选，6–32 位；为空时使用默认密码 |

```json
{ "code": 0, "data": { "id": 3, "username": "stu002", "password": "12345678" } }
```

用户名重复返回 `40001 用户名已存在：xxx`。

### 7.5 GET /api/me/ai-config

**权限**：登录用户。返回当前账号的 AI 配置，API Key 只返回打码值。

```json
{
  "code": 0,
  "data": {
    "enabled": true,
    "baseUrl": "https://dashscope.aliyuncs.com/compatible-mode/v1",
    "model": "qwen-plus",
    "hasApiKey": true,
    "apiKeyMasked": "sk-****csAI",
    "updatedAt": "2026-11-18T16:47:54.583"
  }
}
```

### 7.6 PUT /api/me/ai-config

保存当前账号的配置。`apiKey` 传 `null` 表示不修改，传空字符串表示清除。

```json
{
  "enabled": true,
  "baseUrl": "https://dashscope.aliyuncs.com/compatible-mode/v1",
  "model": "qwen-plus",
  "apiKey": "sk-..."
}
```

`baseUrl` 必须以 `http://` 或 `https://` 开头。

### 7.7 POST /api/me/ai-config/test

向已保存的端点发起一次最小请求，验证 Key 与端点可用。

```json
{ "code": 0, "data": { "ok": true, "model": "qwen-plus", "elapsedMs": 1100 } }
```

失败时 `ok=false` 并带 `message`。

### 7.8 管理员查看/清空用户 AI 配置

- `GET /api/admin/users/{id}/ai-config`：返回同 7.5 的结构，Key 打码
- `DELETE /api/admin/users/{id}/ai-config`：删除该用户配置，之后其 AI 助教不可用

### 7.9 GET /api/admin/users/{id}

返回指定用户的基本信息。

```json
{
  "code": 0,
  "data": {
    "id": 2,
    "username": "stu001",
    "nickname": "示例学生",
    "role": "STUDENT",
    "status": 1,
    "avatarUrl": "/uploads/avatars/u2_1795062316581.png",
    "createdAt": "2026-11-15T19:26:53.226+08:00"
  }
}
```

用户不存在返回 `40401`。

### 7.10 PATCH /api/admin/users/{id}

编辑指定用户的昵称与角色。

```json
{ "nickname": "新昵称", "role": "STUDENT" }
```

| 字段 | 规则 |
|---|---|
| nickname | 可选，≤32 字符；空字符串回退为用户名；不传表示不修改 |
| role | 可选，仅 `ADMIN` / `STUDENT`；不传表示不修改 |

| 约束 | 说明 |
|---|---|
| 不能修改当前登录账号的角色 | 返回 `40001` |
| 不能把最后一个启用状态的管理员降级 | 返回 `40001` |
| 用户不存在 | 返回 `40401` |

```json
{ "code": 0, "message": "ok", "data": null }
```

### 7.11 DELETE /api/admin/users/{id}

删除账号，并级联清理该用户的提交记录、测试点结果、AI 问答记录、AI 配置与比赛报名。

| 约束 | 说明 |
|---|---|
| 不能删除当前登录账号 | 返回 `40001` |
| 不能删除最后一个启用状态的管理员 | 返回 `40001` |
| 用户不存在 | 返回 `40401` |

```json
{ "code": 0, "message": "ok", "data": null }
```

### 7.12 POST /api/admin/users/{id}/avatar

管理员为指定用户上传头像，`multipart/form-data`，字段名 `file`。

| 约束 | 说明 |
|---|---|
| 文件格式 | 仅支持 png / jpg / jpeg / webp |
| 文件大小 | 不超过 2MB |

```json
{ "code": 0, "data": { "avatarUrl": "/uploads/avatars/u2_1795062316581.png" } }
```

### 7.13 DELETE /api/admin/users/{id}/avatar

移除指定用户的头像。

```json
{ "code": 0, "message": "ok", "data": null }
```

### AI 可用性判定

`GET /api/ai/status` 返回当前用户的判定结果：

```
enabled = 全局开关 && 用户配置启用 && 端点非空 && 已保存 Key
```

未满足时 `enabled=false`，前端不渲染助教入口并在顶部提示；`POST /api/submissions/{id}/hint` 返回 `40001 请先在个人设置中配置 AI 模型`。

## 8 个人中心

### 8.1 GET /api/me/profile

**权限**：登录用户。返回当前账号资料。

```json
{
  "code": 0,
  "data": {
    "id": 1,
    "username": "admin",
    "nickname": "管理员",
    "role": "ADMIN",
    "avatarUrl": "/uploads/avatars/u1_1794994156669.png",
    "createdAt": "2026-11-15T19:26:53.218"
  }
}
```

### 8.2 PUT /api/me/profile

```json
{ "nickname": "新昵称" }
```

昵称 1–32 字符，返回更新后的资料。

### 8.3 PUT /api/me/password

```json
{ "oldPassword": "当前密码", "newPassword": "新密码" }
```

新密码 6–32 位；当前密码错误返回 `40001 当前密码不正确`；新旧相同同样拒绝。

### 8.4 POST /api/me/avatar

`multipart/form-data`，字段名 `file`。

| 限制 | 值 |
|---|---|
| 大小 | ≤ 2MB |
| 类型 | png / jpg / jpeg / webp |

```json
{ "code": 0, "data": { "avatarUrl": "/uploads/avatars/u1_1794994244972.png" } }
```

头像保存于 `oj.upload.dir`（默认 `./uploads`），通过 `GET /uploads/**` 公开访问，**不需要认证**（否则 `<img>` 无法加载）。

### 8.5 DELETE /api/me/avatar

移除头像并删除磁盘文件，`avatarUrl` 置空。

### 8.6 GET /api/me/stats

**Query**：`days` 可选，统计天数，默认 7，范围 1–90。

```json
{
  "code": 0,
  "data": {
    "today": { "submissions": 2, "accepted": 1, "acceptanceRate": 50, "solvedProblems": 1 },
    "trend": [
      { "date": "2026-11-12", "submissions": 0, "accepted": 0, "solvedProblems": 0 },
      { "date": "2026-11-18", "submissions": 2, "accepted": 1, "solvedProblems": 1 }
    ],
    "byDifficulty": [
      { "key": "1", "label": "简单", "submissions": 9, "accepted": 4, "solvedProblems": 2 }
    ],
    "byTag": [
      { "key": "基础运算", "label": "基础运算", "submissions": 9, "accepted": 4, "solvedProblems": 2 }
    ]
  }
}
```

`trend` 返回近 `days` 天，缺失日期补 0；`accepted` 为当天 AC 次数，`solvedProblems` 为当天 AC 的不同题目数；`acceptanceRate` 为百分比（0–100，保留两位）。

`byDifficulty` 按难度聚合（`key` 为 1/2/3），`byTag` 按题目 `tags` 聚合（一题多标签会计入每个标签）；两者只返回窗口内有提交的维度，按通过题目数降序。

### 8.7 刷题记录

复用 `GET /api/submissions?page=&size=`，个人中心每页 10 条，点击某行跳转 `/submissions/{id}`。

## 9 比赛

比赛状态由服务器时间派生，不额外存状态列：

| 状态 | 条件 |
|---|---|
| `DRAFT` | `published=0`，仅管理员可见 |
| `UPCOMING` | `now < start_at` |
| `RUNNING` | `start_at <= now < freeze_at`（无封榜时到 `end_at`） |
| `FROZEN` | `freeze_at <= now < end_at` |
| `ENDED` | `now >= end_at` |

### 9.1 GET /api/contests

**权限**：登录

**Query**：`keyword`（可选，标题模糊搜索）

**响应 200** `data[]` 元素：

```json
{
  "id": 2,
  "title": "算法热身赛",
  "mode": "ICPC",
  "phase": "RUNNING",
  "startAt": "2026-11-19T21:57:00",
  "endAt": "2026-11-19T23:59:00",
  "freezeAt": "2026-11-19T23:30:00",
  "joinType": "PUBLIC",
  "published": true,
  "registered": true,
  "participantCount": 12,
  "problemCount": 5
}
```

### 9.2 GET /api/contests/{id}

**权限**：登录

**响应 200**：`ContestListItem` 字段 + `description`、`canRegister`、`problems[]`。

- `problems[]` 元素：`problemId`、`alias`、`orderNo`、`title`、`difficulty`、`passed`、`score`。
- `UPCOMING` 阶段 `problems` 为空数组，避免赛前泄漏题目标题；`problemCount` 仍返回真实数量。
- `canRegister = phase=UPCOMING && !registered`。
- 错误：`40401`（比赛不存在或未发布）。

### 9.3 POST /api/contests/{id}/register

**权限**：登录

**请求**：`{ "password": "可选，密码报名时必填" }`

**规则**

- 仅在 `start_at` 之前允许自助报名；比赛开始后需管理员代报名。
- 已报名重复调用直接返回成功（幂等）。
- `PASSWORD` 报名使用 BCrypt 校验；`PUBLIC` 忽略密码。

**错误**：`40001`（密码错误 / 比赛已开始 / 不支持自助报名）、`40401`

### 9.4 GET /api/contests/{id}/problems/{problemId}

**权限**：已报名且比赛已开始（管理员走管理端）

**响应 200**：与 2.2 题目详情结构一致，但允许访问对普通题库隐藏的题目；仍**绝不返回测试点数据**。

**错误**：`40301`（未报名 / 比赛尚未开始）、`40401`（题目不属于该比赛）

### 9.5 GET /api/contests/{id}/standings

**权限**：已报名

**响应 200**

```json
{
  "contestId": 2,
  "phase": "FROZEN",
  "frozen": true,
  "freezeAt": "2026-11-19T23:30:00",
  "updatedAt": "2026-11-19T23:35:12",
  "items": [
    {
      "rank": 1,
      "userId": 4,
      "username": "stu001",
      "nickname": "张三",
      "solved": 3,
      "penalty": 128,
      "lastAcAt": "2026-11-19T23:10:00",
      "problems": { "A": "+0", "B": "+2", "C": "-3", "D": "" }
    }
  ]
}
```

**计分规则**

- `solved`：比赛时间窗内 AC 的不同题目数。
- `penalty`：首次 AC 距开始的分钟数 + `20 × 首次 AC 前的非 AC 提交数`（编译错误 CE 不计罚时）。
- 排序：`solved DESC`、`penalty ASC`、最后 AC 时间早者优先。
- 封榜：公开榜只统计 `created_at < freeze_at` 的提交；`frozen=true` 时提示封榜；管理员接口返回全量。
- `problems` 的键为题目 alias，值 `+n` 表示 AC（n 次错误）、`-n` 表示未 AC 的尝试次数、空串表示未提交。

### 9.6 比赛提交

沿用 3.1 `POST /api/submissions`，请求增加可选 `contestId`：

```json
{ "problemId": 5, "contestId": 2, "language": "PYTHON3", "code": "..." }
```

- 校验比赛已发布、当前时间在 `[start_at, end_at)`、用户已报名、题目属于该比赛。
- **跳过 10 分钟幂等复用**，确保每次尝试都记录并计入罚时。
- 写入 `submission.contest_id`；练习提交该字段为 `NULL`。
- 比赛进行中禁用 AI 助教；历史代码入口在比赛页面隐藏。
- 错误：`40001`（比赛未开始/已结束、题目不属于比赛）、`40301`（未报名）、`40401`（比赛/题目不存在）。

### 9.7 管理接口（ADMIN）

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/admin/contests?page=&size=&keyword=` | 全量比赛（含草稿），返回分页 |
| GET | `/api/admin/contests/{id}` | 比赛详情（含全部题目映射，不受赛前隐藏限制） |
| POST | `/api/admin/contests` | 创建比赛，返回 `{ "id": n }` |
| PUT | `/api/admin/contests/{id}` | 修改标题、时间、封榜、报名方式、发布状态 |
| DELETE | `/api/admin/contests/{id}` | 删除比赛：删除报名与题目映射，比赛内提交保留并置 `contest_id=NULL` |
| PUT | `/api/admin/contests/{id}/problems` | 整体替换比赛题目（`problemId`、`alias`、`orderNo`、`score`） |
| GET | `/api/admin/contests/{id}/standings` | 全量榜单（封榜后仍可见） |
| POST | `/api/admin/contests/{id}/participants/{userId}` | 管理员代报名 |

**创建/修改校验**：`startAt < endAt`；`freezeAt` 必须在比赛时间范围内；`mode` 为 `ICPC`/`OI`；`joinType` 为 `PUBLIC`/`PASSWORD`；密码报名首次创建必须提供密码。
